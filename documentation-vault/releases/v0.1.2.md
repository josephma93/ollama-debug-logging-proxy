# v0.1.2

**Released:** 2026-09-25

## Summary

Patch release so LAN clients can reach Ollama through the proxy using any DNS name, not only IP addresses or `.local` names.

## Highlights

- The proxy now forwards the target host as the upstream `Host` header instead of the client-supplied one.
- Requests addressed to a LAN DNS name such as `<host>.<lan-domain>:11434` no longer receive `403 Forbidden` from Ollama.

## Changes

### Added

- Integration test `TestProxyRewritesHostToTarget` covering the upstream `Host` header.

### Changed

- Upstream requests carry `Host` set to the `OLLAMA_PROXY_TARGET` host.

### Fixed

- Ollama bound to loopback rejects unrecognized `Host` headers with `403`. Clients using a DNS name other than an IP, `localhost`, or a `.local` / `.internal` / `.localhost` suffix were blocked even though the proxy itself accepted the connection.

### Removed

- None.

## Migration notes

None. Restart the `dev.ollama.logging-proxy` LaunchAgent after upgrading.
